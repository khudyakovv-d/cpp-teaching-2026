# Задача 0а. Две версии проекта

В папке находятся две готовые версии одной программы. Это материал для демонстрации преподавателя, а не самостоятельное задание: студентам не нужно повторять переход между версиями во время занятия.

Исходный код в версиях одинаковый. Отличаются структура каталогов и описание сборки в CMake.

## 1. Одна исполняемая цель

[Открыть первую версию](01-single-target/README.md).

```text
main.cpp + module1.cpp + module2.cpp → программа lab0a
```

Все три `.cpp` входят в одну исполняемую цель. С этой версии удобно начать: на ней видны компиляция, линковка, объектные файлы и работа пространств имён.

## 2. Один модуль как библиотека

[Открыть вторую версию](02-library-targets/README.md).

```text
module1.cpp → статическая библиотека module1 ─┐
                                              ├→ программа lab0a
main.cpp + module2.cpp ───────────────────────┘
```

Во второй версии `module1` становится отдельной статической библиотекой. `main.cpp` и `module2.cpp` по-прежнему входят в исполняемую цель `lab0a`.

Преподавателю достаточно открыть и собрать обе папки по очереди, а затем сравнить их `CMakeLists.txt` и результаты в каталогах `build`. Так внимание остаётся на различии между одной целью и связкой «библиотека + программа», а не на переносе файлов.
