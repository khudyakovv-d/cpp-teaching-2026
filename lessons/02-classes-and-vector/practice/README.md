# Учебный Vector

Реализация к [занятию 2](../README.md). Ниже — комментарии к коду класса в [vector.h](vector.h) и [vector.cpp](vector.cpp). [main.cpp](main.cpp) демонстрирует его использование.

## Поля и создание объекта

**`arr_` и `size_`.** Вектор владеет массивом по адресу `arr_`; `size_` хранит количество элементов. У пустого вектора `arr_ == nullptr` и `size_ == 0`. Поля закрыты, чтобы вызывающий код не мог независимо менять указатель и размер.

**`Vector()`.** Присваивает полям `nullptr` и 0 в теле конструктора. Массив для пустого вектора не выделяется.

**`Vector(int size)`.** Сначала задаёт пустое состояние через список инициализации. Отрицательный размер отклоняется до выделения памяти. Для положительного размера `new int[size]{}` создаёт массив и обнуляет элементы. При нуле указатель остаётся `nullptr`. `explicit` в объявлении запрещает неявно превращать число в `Vector`.

**`~Vector()`.** Освобождает массив через `delete[] arr_`. Отдельная проверка пустого вектора не нужна: `delete[] nullptr` допустим.

## Доступ к элементам

**`size() const`.** Возвращает `size_` по значению. Метод доступен и для константного вектора.

**Две версии `operator[]`.** Обе возвращают `arr_[i]`, но с разными типами результата: `int&` позволяет записывать в элемент, `const int&` — только читать через полученную ссылку. Вторую версию выбирают при обращении к константному вектору. Проверки границ в реализации нет: вызывающий код должен соблюдать `0 <= i && i < size()`.

## Копирование и присваивание

**`Vector(const Vector& vec)`.** Создаёт собственный массив размером `vec.size_` и копирует в него элементы. Предварительно обнулять массив здесь не требуется: цикл запишет каждый элемент до его чтения. Для пустого источника выделение памяти и копирование пропускаются.

**`operator=(const Vector& vec)`.** Проверка `this == &vec` сразу завершает самоприсваивание. Для остальных случаев сначала выделяется `newArr` и копируются элементы. Только после этого удаляется прежний массив и обновляются поля получателя. Если выделение памяти завершится исключением, прежнее содержимое останется целым; копирование элементов `int` исключений не выбрасывает.

Возвращаемый `*this` — ссылка на получателя, поэтому возможно выражение `a = b = c`. После замены массива прежние ссылки и указатели на его элементы больше использовать нельзя.

## Сложение

**`operator+(const Vector& other) const`.** До обращения к элементам проверяет равенство размеров. Затем создаёт `result`, заполняет его поэлементной суммой и возвращает по значению. Исходные векторы не изменяются. Переполнение `int` не проверяется: примеры используют небольшие числа.

## Запуск

Откройте эту папку в VS Code. Выберите пресет `Build`, выполните `CMake: Configure` и `CMake: Build`, затем выберите цель `vector_demo` через `CMake: Set Launch/Debug Target` и запустите `CMake: Run Without Debugging`.

Для готовых проверок выберите цель `vector_test`. При успешном запуске она выводит `Vector checks passed`.
