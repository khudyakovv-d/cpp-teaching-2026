# Занятие 3. Исключения и владение ресурсами

На прошлом занятии `Vector` сообщал об ошибке через `throw`. Теперь проследим, куда попадает исключение, что происходит с уже созданными объектами и каким остаётся объект после неудачной операции.

Материалы идут в таком порядке:

1. [Как сообщить об ошибке](theory/01-errors-and-handlers.md) — коды возврата в C и Go, `throw`, `try` и несколько `catch`.
2. [Что происходит с ресурсами](theory/02-unwinding-and-ownership.md) — раскрутка стека, утечки, RAII, исключение из конструктора и `noexcept`.
3. [Каким останется объект](theory/03-exception-safety.md) — базовая и сильная гарантии на одном примере.
4. [Демонстрационный проект](practice/README.md) — запуск примеров из теории.

После занятия студент сможет проследить путь исключения, определить, какие объекты уничтожатся, найти утечку при ручном управлении памятью и объяснить состояние объекта после ошибки.

Для занятия нужны классы, конструкторы, деструкторы и копирование из [занятия 2](../02-classes-and-vector/README.md). Иерархию исключений и собственные классы исключений оставляем до наследования.
