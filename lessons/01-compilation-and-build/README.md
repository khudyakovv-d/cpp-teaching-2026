# Занятие 1. Компиляция и сборка проекта

На этом занятии разбираем, как исходный код превращается в программу и какую роль в этом процессе играет CMake.

Сборку `lab0a` показывает преподаватель. Студенты повторят этот процесс самостоятельно позже, при выполнении задачи 0b.

Материалы расположены в порядке изучения:

1. [Путь от исходного кода до программы](01-source-to-executable.md).
2. [Системы сборки и CMake](02-build-systems-and-cmake.md).
3. [Цели и основные команды CMake](03-cmake-targets.md).
4. [Демонстрационный проект задачи 0а](../../lab0a/README.md).

После занятия студент должен различать компиляцию и линковку, понимать назначение CMake, видеть связи между целями и уметь собрать готовый CMake-проект через интерфейс Visual Studio Code.
