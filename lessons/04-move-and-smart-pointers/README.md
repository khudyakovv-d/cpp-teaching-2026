# Занятие 4. Перемещение и умные указатели

Наш `Vector` уже умеет хранить данные, создавать независимые копии и освобождать память. Теперь представим, что рабочая версия готова, а прежнему владельцу она больше не нужна. Зачем выделять ещё один массив и копировать элементы, если можно передать уже существующий массив другому объекту?

Материалы идут в таком порядке:

1. [От передачи ресурса к std::move](theory/01-move-and-expressions.md) — смысл перемещения, категории выражений и ссылки `T&&`.
2. [Конструктор и оператор перемещения](theory/02-moving-vector.md) — реализация на `Vector`, состояние источника, `noexcept` и возврат по значению.
3. [Умные указатели](theory/03-smart-pointers.md) — единоличное и совместное владение, наблюдение и циклы.
4. [Демонстрационный проект](practice/README.md) — сборка и запуск примеров.

Блоки кода — отдельные фрагменты; для `std::move` нужен `<utility>`, для умных указателей — `<memory>`, для вывода — `<iostream>`. Полный проект находится в `practice`. В конце каждой части есть вопросы с ответами для самопроверки.

После занятия студент сможет отличить копирование от перемещения, реализовать передачу массива в `Vector`, выбрать способ владения объектом и объяснить, когда объект будет уничтожен.

Нужны [копирование и присваивание](../02-classes-and-vector/theory/04-copy-and-assignment.md), а также [RAII и `noexcept`](../03-exceptions/theory/02-unwinding-and-ownership.md). Здесь используем эти понятия без повторного разбора. Примеры рассчитаны на C++20; шаблонные типы стандартной библиотеки используем в готовом виде. Наследование, многопоточность и написание собственных шаблонов для этого занятия не нужны.
