# От передачи ресурса к std::move

Наш `Vector` умеет создавать независимую копию массива. Это нужно, пока исходные данные должны сохраняться. Но представим, что мы подготовили новые измерения и теперь заменяем ими действующие:

```cpp
Vector active(1000);
Vector prepared(1000);
// Заполняем и проверяем prepared.
active = prepared;
```

Копирующее присваивание выделит ещё один массив и скопирует тысячу чисел. Если `prepared` после этого больше не нужен в прежнем виде, можно обойтись без этой работы: передать уже готовый массив в `active`.

## Что именно перемещается

У вектора есть адрес массива `arr_` и размер `size_`. Чтобы передать ресурс между **двумя разными объектами**, внутри класса достаточно выполнить знакомые действия:

```cpp
// Фрагмент метода: получатель — *this, источник — source.
delete[] arr_;           // Освобождаем старый массив получателя.
arr_ = source.arr_;      // Принимаем адрес готового массива.
size_ = source.size_;
source.arr_ = nullptr;   // Источник больше не отвечает за этот массив.
source.size_ = 0;
```

Числа остаются на прежнем месте в памяти. Меняется **владелец** — объект, который должен освободить массив. Источник продолжает существовать, но теперь пуст. Его деструктор выполнит безопасный `delete[] nullptr`, а переданный массив позже удалит получатель.

Такую передачу ресурса называют **перемещением**. В нашем классе копирование создаёт независимый массив и сохраняет источник, а перемещение забирает массив и меняет источник. Получатель не становится ссылкой на источник: это по-прежнему два разных `Vector`.

Сам алгоритм можно оформить обычным методом с параметром `Vector&`. Но C++ позволяет использовать перемещение при создании и присваивании объектов. Сначала разберём, как сообщить, что ресурс источника разрешено забрать, а затем оформим алгоритм в соответствующие функции класса.

## Выражение и его категория

**Выражение** — вычисляемая часть программы: например, `count`, `*pointer` или `count + 1`. У выражения есть тип и категория. Тип говорит, с какими данными мы работаем; категория помогает различать способы получения результата.

```cpp
int count = 10;
int* pointer = &count;
int numbers[2] = {20, 30};
```

Выражения `count`, `*pointer` и `numbers[0]` относятся к **lvalue**: это обычные обращения к существующим объектам, без представления их как источников перемещения. Первые два обозначают одну переменную `count`, третье — элемент массива. Через них можно обратиться к тому же объекту повторно или связать с ним ссылку:

```cpp
int& alias = *pointer;
alias = 15; // Изменился count.
```

Lvalue не обязательно имеет отдельное имя: `numbers[0]` тоже lvalue. И категория не зависит от стороны присваивания:

```cpp
int copy = count; // count справа, но по-прежнему lvalue.
const int limit = 100; // При обращении limit тоже lvalue.
// limit = 200; // Изменять его нельзя из-за const.
```

Историческое название *left value* не означает «всё, чему можно присвоить»: категория выражения и возможность изменять объект — разные свойства.

## Prvalue: вычислить новое значение

У `count + 1` тоже тип `int`, но это выражение вычисляет новое значение, а не обозначает сам `count`. Такая категория называется **prvalue** (*pure rvalue*). Другие примеры — число `42` и выражение `Vector(3)`, которым можно инициализировать новый вектор:

```cpp
Vector values = Vector(3);
```

Здесь `Vector(3)` — prvalue, а последующее обращение `values` — lvalue. Категория правой части не закрепляется за новой переменной. В C++20 этот пример создаёт `values` сразу, без обязательного промежуточного вектора и его копирования.

## Как разрешить перемещение именованного объекта

Выражение `prepared` — lvalue. Обычное обращение к нему не сообщает, что его массив можно забрать. Для явного разрешения используется `std::move` из `<utility>`:

```cpp
active = std::move(prepared);
```

`std::move(prepared)` обозначает тот же объект, но имеет категорию **xvalue** (*expiring value*). В данном случае она позволяет рассматривать существующий объект как источник передачи ресурса. Она не означает, что источник немедленно уничтожается.

**`std::move` сам ничего не переносит.** Он меняет категорию выражения, позволяя выбрать перемещение. Освободить прежний массив получателя, передать адрес и обнулить источник должен код самого `Vector` — как в алгоритме выше. В версии класса из занятия 2 move-операций ещё нет, поэтому такое присваивание пока вызовет копирование.

## Prvalue и xvalue — две разновидности rvalue

Мы рассмотрели два разных случая: получить новое значение и разрешить использовать ресурс существующего объекта. В языке они объединены общим названием **rvalue**:

- **Prvalue** вычисляет значение или инициализирует объект: `42`, `count + 1`, `Vector(3)`.
- **Xvalue** обозначает существующий объект, который можно использовать как источник перемещения: например, `std::move(prepared)`.

**Граница проходит по способу обращения, а не по самому объекту.** Lvalue — обычное обращение к объекту. Rvalue — либо вычисление нового значения (prvalue), либо обращение к объекту как к источнику перемещения (xvalue). Поэтому rvalue — общее название для двух разновидностей, а не третья категория рядом с ними.

Сравним создание векторов после добавления move-операций:

```cpp
Vector values(3);
Vector copy = values;             // values — lvalue: создаётся копия.
Vector fresh = Vector(3);         // Vector(3) — prvalue: создаётся новый объект.
Vector taken = std::move(values); // std::move(values) — xvalue: массив передаётся.
```

`values` и `std::move(values)` обозначают **один и тот же объект**, но по-разному участвуют в выборе операции. Поэтому наличие имени или адреса не отделяет lvalue от rvalue. Lvalue также не означает запрет менять объект: через `Vector&` его можно изменить. Различие важно именно для выбора между обычным обращением и использованием в качестве источника перемещения.

Обе разновидности rvalue можно принять ссылкой `T&&`. Это связывает категории выражений с выбором функции.

## Ссылка для выбора операции

Знакомая `Vector&` связывается с неконстантным lvalue. Для приёма rvalue конкретного типа используется **rvalue-ссылка** `Vector&&`:

```cpp
Vector values(3);
Vector& ordinary = values;
Vector&& temporary = Vector(3);
Vector&& permitted = std::move(values);
// Vector&& bad = values; // Ошибка: здесь нужен rvalue.
```

`temporary` связывается с временным вектором и в этой форме объявления продлевает его жизнь до конца жизни ссылки. `permitted` связывается с уже существующим `values`. Сама привязка ссылки не передаёт массив и не создаёт второй `Vector`.

Тип параметра позволяет выбрать перегрузку функции:

```cpp
void inspect(Vector&)  { std::cout << "lvalue\n"; }
void inspect(Vector&&) { std::cout << "rvalue\n"; }

Vector values(3);
inspect(values);            // lvalue
inspect(Vector(3));         // prvalue: разновидность rvalue.
inspect(std::move(values)); // xvalue: разновидность rvalue.
```

Эти функции только печатают текст: даже последний вызов не меняет содержимое `values`. Передача ресурса произойдёт, только если выбранная функция её реализует.

У параметра `Vector&& source` есть важная особенность: обращение по имени `source` — lvalue. Чтобы передать его дальше как источник перемещения, пишут `std::move(source)`. Категория относится к выражению, а не навсегда к переменной.

`const Vector&` может принять и lvalue, и rvalue, поэтому удобна для чтения. `std::move` не снимает `const`: из константного источника нельзя получить изменяемую `Vector&&`. При доступном копировании такой источник будет скопирован.

**Проверьте себя:** передаст ли массив строка `Vector&& alias = std::move(values)`? Почему наличие `std::move` ещё не доказывает, что произошло перемещение?

<details>
<summary>Ответ</summary>

Строка только связывает ссылку с существующим объектом. `std::move` меняет категорию выражения; действия с ресурсом определяются вызванной функцией.

</details>
