## Как устроен репозиторий

Материалы каждого занятия находятся в отдельной папке `lessons/NN-topic`. Файлы внутри пронумерованы в порядке чтения, а `README.md` связывает теорию с практическими проектами.

Демонстрационные примеры и практические проекты находятся в папках `lab...` в корне репозитория. Например, материалы первого занятия ведут к демонстрации [lab0a](lab0a/README.md).
